## Scenario Description
This Dart console program models an e-commerce order receipt for a Mechanical Gaming Keyboard purchase. It calculates subtotal, sales tax, box packaging units using integer division (~/) and modulo (%) operators, and evaluates free shipping qualification using comparison operators.


## How to Run
Ensure Dart SDK is installed, then run the following command in the terminal:

```bash
dart run bin/dart_exercises.dart
```
